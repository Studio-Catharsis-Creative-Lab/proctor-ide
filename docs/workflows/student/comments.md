# Student workflow — collaboration comments

When enabled, you can attach **comments** to lines of code for discussion with instructors or TAs.

## Authentication

- Real-time connections should use a **secure token** (e.g. Firebase ID token in the WebSocket URL in modern deployments).
- **Do not** share your token with others.

## Conduct

- Stay **professional**; comments may be retained per [Retention](../../procedures/retention.md).
