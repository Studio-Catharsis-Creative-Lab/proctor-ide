# Instructor workflow — challenges

**Challenges** are typically **low-stakes practice**: experimentation, optional drills, or exploration.

## Goals

- Reduce anxiety and encourage **volume of practice**.
- Keep tracking **light** so logs do not overwhelm instructors.

## Configuration

- **Tracking level**: usually **minimal** (see [matrix](../../reference/activity-types-matrix.md)).
- Clear labeling in the dashboard so students know this is **practice**, not a graded exam.

## Instructor workload

- Spot-check submissions only if you use challenges for **participation credit**.
- Otherwise rely on **auto-run** success or completion markers if enabled.

## Transparency

- Still disclose **minimal** logging in student-facing copy—practice does not mean “no logging,” but it should be proportionate.
