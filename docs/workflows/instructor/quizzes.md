# Instructor workflow — quizzes

**Quizzes** are short, focused checks—often time-bounded—with **basic** integrity expectations.

## Design tips

- Keep prompts **atomic** (one concept per item when possible).
- Align **time limits** with what a prepared student needs; document rounding rules for ties.

## Configuration

- **Tracking level**: typically **basic** (focus changes, paste detection where enabled, time bounds).
- Decide whether students can **navigate backward** between items (product capability permitting).

## Before students start

- Publish **integrity rules** in the syllabus and reference the in-product **transparency** banner.

## Review

- Use submission timestamps and basic signals; escalate anomalies per [Incident response](../../procedures/incident-response.md).
