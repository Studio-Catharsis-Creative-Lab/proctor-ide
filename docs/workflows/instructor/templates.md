# Instructor workflow — templates and starter code

## Purpose

Templates give every student a **consistent starting point** and reduce setup friction.

## Recommended contents

| File | Purpose |
|------|---------|
| `ASSIGNMENT.md` | Student-facing instructions, rubric summary, allowed resources |
| Starter source files | Minimal compilable/runnable skeleton |
| Data files | Small fixtures if needed (watch size limits) |

## Practices

- Keep templates **small** and **scannable**; link to longer readings externally if needed.
- Avoid secrets (API keys); use **environment placeholders** documented in instructions.
- Version templates in **Git** outside the LMS if you maintain a canonical repo; upload the **release snapshot** into ProctorIDE.

## After upload

- Smoke-test by opening the activity as a **sandbox student account** if permitted.
