# Workflows overview

Workflow documentation is split by **persona**. Each path describes **happy paths**, **exceptions**, and pointers to **transparency** and **compliance** topics.

## Instructor / TA

Start at [Instructor hub](instructor/index.md). Typical sequences:

1. Create activity → set type and tracking → upload template → enroll → monitor → review submissions.

## Student

Start at [Student hub](student/index.md). Typical sequences:

1. Dashboard → acknowledge transparency if shown → start activity → edit/run → submit.

## Administrator / IT

Start at [Admin hub](admin/index.md) for deployment, networking, and secrets.
