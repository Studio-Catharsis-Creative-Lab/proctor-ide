# Accessibility

## Goals

Courseware should be usable by learners with **diverse abilities**. For the web IDE:

- Keyboard **navigation** for editor and primary actions (subject to Monaco/editor limits).
- **Sufficient contrast** in themes; avoid **color-only** status cues where possible.
- **Screen reader**: complex IDE surfaces remain challenging—offer **documented alternatives** (extended time, alternate format) per disability services.

## Process

- Track **WCAG** targets with your institution’s digital accessibility office.
- File issues for **blocking** defects (cannot submit, cannot read errors).
