# Audit expectations

Auditors (internal IT, risk, or external assessors) typically ask for **evidence** that controls exist and operate.

## Common evidence artifacts

| Control area | Example evidence |
|--------------|------------------|
| **Access** | IAM export, quarterly [access reviews](../procedures/access-reviews.md) notes. |
| **Change management** | PR history, CI green builds, deployment logs. |
| **Logging** | Centralized API logs with **retention** matching policy. |
| **Vendor risk** | Current [subprocessor list](../procedures/vendors-subprocessors.md), DPAs. |
| **Training** | Instructor integrity training records (outside this repo). |
