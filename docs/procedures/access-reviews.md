# Access reviews

## Scope

Review **quarterly** (or per campus policy):

- **Cloud project** owners and **IAM** bindings (Firebase, GCP, database admin).
- **Repository** admins for this codebase.
- **Production secrets** distribution list.

## Instructor / TA access

- Confirm staff **lost access** when courses end.
- Prefer **course-scoped** roles over global superuser accounts.

## Evidence

Keep a lightweight log: **date**, **reviewer**, **systems checked**, **follow-ups**.
