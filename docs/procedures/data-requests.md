# Data requests (students, parents, legal)

!!! warning "Not legal advice"
    Coordinate all formal requests with your **privacy office** and **counsel**.

## Student access / correction

Many institutions provide portals for **education records** access. For ProctorIDE-hosted data:

1. **Identify** the subject (verified identity).
2. **Locate** records: database queries by **UID / email** per schema.
3. **Export** in a common format (CSV/PDF of submissions) where feasible.
4. **Respond** within institutional timelines.

## Deletion

- **Course completion** may still require **retention** for grades disputes—do not delete blindly.
- **Anonymization** may satisfy some policies when raw deletion conflicts with transcripts.

## Law enforcement / subpoenas

- Route through **legal**; preserve chain of custody for logs.
