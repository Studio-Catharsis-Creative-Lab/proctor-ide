# Operational procedures

These procedures support **security**, **privacy**, and **continuity** for institutions running ProctorIDE.

| Procedure | When to use |
|-----------|-------------|
| [Incident response](incident-response.md) | Suspected breach, outage, or data leak. |
| [Access reviews](access-reviews.md) | Periodic verification of admin and instructor privileges. |
| [Data requests](data-requests.md) | Student or parent requests; subpoenas—coordinate with legal. |
| [Retention](retention.md) | Align backups and databases with policy. |
| [Vendors & subprocessors](vendors-subprocessors.md) | Onboarding IdPs, hosting, AI tools, analytics. |
| [Testing policy](testing-policy.md) | How the engineering team validates releases (CI, manual smoke). |
