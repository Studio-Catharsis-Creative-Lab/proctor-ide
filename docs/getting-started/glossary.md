# Glossary

| Term | Definition |
|------|------------|
| **Activity** | A unit of work in a course: assignment, project, challenge, quiz, test, or exam. Each has a **type** and **tracking level**. |
| **Assignment** | Longer-form work; often **moderate** tracking (edits, run events, version history). |
| **Project** | Multi-file or longer effort; may share the same product path as an assignment with different rubric in the syllabus. |
| **Challenge** | Low-stakes practice; typically **minimal** tracking. |
| **Quiz** | Shorter assessment; **basic** integrity (time, focus, paste in some designs). |
| **Test / exam** | High-stakes; **comprehensive** tracking; may add proctoring features as your institution enables them. |
| **Tracking level** | Configured intensity of behavioral and technical logging (see [matrix](../reference/activity-types-matrix.md)). |
| **Workspace** | Your **isolated** file area for an activity; version history is stored **on the server**; you do not use raw Git commands. |
| **Timeline** | History of saved versions (backed by the platform’s version control), used for recovery and review. |
| **Run** | Executing code in a **sandbox** (e.g. Judge0) and returning output; runs can be **logged** for integrity. |
| **Invitation** | A code or link that grants access with a **role** and **expiry**. |
| **Enrollment** | Association between a **student** and an **activity** (and status: not started, in progress, submitted, etc.). |
| **FERPA (US)** | Family Educational Rights and Privacy Act; governs access to **education records** in U.S. schools. This doc set uses a **practical** framing only—[see disclaimer](../compliance/disclaimer.md). |
