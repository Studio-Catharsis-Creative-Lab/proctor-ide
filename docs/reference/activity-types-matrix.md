# Activity types matrix

Compact reference aligned with [Tracking by activity type](../transparency/tracking-by-activity-type.md).

| Type | Typical stakes | IDE depth | Tracking tier |
|------|----------------|-----------|----------------|
| **Challenge** | Low (practice) | Full | **Minimal** |
| **Quiz** | Medium-low | Moderate | **Basic** |
| **Assignment / project** | Medium-high | Full | **Moderate** |
| **Test / exam** | High | Full + tight rules | **Comprehensive** |

## Configuration knobs

Instructors may still adjust **due dates**, **files**, and **collaboration**—always document exceptions in the syllabus.
